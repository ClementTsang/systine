# systine

[<img src="https://img.shields.io/crates/v/systine.svg?style=flat-square" alt="crates.io link">](https://crates.io/crates/systine)
[<img src="https://docs.rs/systine/badge.svg">](https://docs.rs/systine)

Get system information in Rust.

A fork of [`sys-info`](https://github.com/FillZpp/sys-info-rs) with a focus on illumos, Solaris, and OpenBSD for use with [bottom](https://github.com/ClementTsang/bottom). Thanks to all who worked on the original crate!

## Usage

Add this to `Cargo.toml`:

```
[dependencies]
systine = "0.1.0"
```
